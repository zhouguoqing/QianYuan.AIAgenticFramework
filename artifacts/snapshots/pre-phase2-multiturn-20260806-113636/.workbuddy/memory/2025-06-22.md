
## 国际化(i18n)审查：cloud.teld6.top

- 站点：https://cloud.teld6.top/ (Intelligent O&M Platform / 运营商服务平台)
- 账号：saasadmin / saasadminA?
- 工具：Playwright + 自定义 Python 审查脚本
- 方法：登录 → 关闭弹窗 → 遍历 15+ 功能页面 → 逐页扫描中文文本

### 结果
- 侧边栏 80 个菜单项全部英文，翻译完成度约 95%
- 发现问题（5 个去重后）：
  1. 全局弹窗标题 `提示信息`（应改为 "Information"）
  2. 全局弹窗按钮 `确定`（应改为 "OK"）
  3. 用户角色 `系统管理员`（出现在每个页面顶部，应改为 "System Administrator"）
  4. 页面 `<title>` 含中文 `运营商服务平台`（应纯英文）
  5. 语言切换器选项 `简体中文`（设计决策问题）
