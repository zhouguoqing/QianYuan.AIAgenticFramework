## 🔴 核心问题清单

### #1 全局弹窗标题：`提示信息` 

| 属性 | 内容 |
|------|------|
| **原文** | `提示信息` |
| **出现位置** | 所有弹窗/dialog 的标题栏 |
| **触发场景** | 会话过期、401 无权限、操作确认等 |
| **影响页面** | 全局（每次显示弹窗都会出现） |
| **问题类型** | 弹窗标题硬编码中文 |
| **修复建议** | i18n 配置添加：`dialog.info.title = "Information"` |

### #2 全局弹窗按钮：`确定`  

| 属性 | 内容 |
|------|------|
| **原文** | `确定` |
| **出现位置** | 所有弹窗的确认按钮 |
| **触发场景** | 与 #1 同时出现 |
| **影响页面** | 全局 |
| **问题类型** | 按钮文本硬编码中文 |
| **修复建议** | i18n 配置添加：`dialog.confirm = "OK"` 或 `"Confirm"` |

### #3 用户角色/身份：`系统管理员`  

| 属性 | 内容 |
|------|------|
| **原文** | `系统管理员` |
| **出现位置** | 页面顶部栏用户信息区域（`<span>` 标签） |
| **出现频率** | **每个页面均出现**（Home / Workbench / Initialize / Business Compass / Revenue Analysis / Risk Control / Charging Station / Pricing Mgmt / Schedule / Station List / Idle Fee Mgmt / Station View / Digital View 等全部 14 个已访问页面） |
| **问题类型** | 数据库存储值/前端展示硬编码中文 |
| **修复建议** | 方案 A: 角色名存储国际化 key，前端通过 i18n 映射渲染（如 `role.system_admin = "System Administrator"`）<br>方案 B: 在用户信息 API 返回值中直接返回英文角色名 |

### #4 页面标题：`运营商服务平台`

| 属性 | 内容 |
|------|------|
| **原文** | `Initialize-Operator Service Platform-运营商服务平台` |
| **出现位置** | 浏览器 `<title>` 标签（标签页标题） |
| **影响页面** | 全局（所有页面共享同一 title） |
| **问题类型** | 页面标题中英文混杂 |

### #5 语言切换器选项：`简体中文`  

| 属性 | 内容 |
|------|------|
| **原文** | `简体中文` |
| **出现位置** | 顶部导航栏语言切换下拉框 |
| **触发场景** | 点击语言切换器时可见 |
| **影响页面** | 全局 |
| **问题类型** | 下拉选项硬编码（注意：此项目在中文环境下是合理的，但在纯英文用户视角下出现中文可能造成困惑） |
