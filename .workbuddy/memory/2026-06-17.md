## 修复 OpenAICompat HTTP 400 "invalid byte in chunk length"
- **根因**: .NET HttpClient 在 macOS/Unix 上自动读取 `http_proxy` 环境变量（本机为 WorkBuddy 沙箱代理 `http://127.0.0.1:49761`），将发往上游的请求经此代理转发；代理破坏了请求体的 chunked 传输编码帧，导致上游 new-api 网关报 `invalid byte in chunk length`。curl 直连上游（`--noproxy`）验证上游完全正常。
- **修复**（2 个文件）:
  1. `src/QianYuan.Providers.OpenAICompat/OpenAICompatExtensions.cs` — 给 HttpClient 配置 `SocketsHttpHandler { UseProxy = false }`，绕过系统/沙箱代理直连上游。
  2. `src/QianYuan.Providers.OpenAICompat/OpenAICompatProvider.cs` — 新增 `JsonContentFromObject` 辅助方法，将请求体预序列化为 `ByteArrayContent`（保证 `Content-Length`，永不退化成 chunked），替换原来的 `JsonContent.Create` 和 `PostAsJsonAsync`。
- 重新 build Release（0 错误）、重启 API、流式 chat 验证通过（模型正常返回 "好"，无 400）。
